# a-share-vix

A股恐慌指数每日数据：每个交易日收盘后（北京时间约15:40）由 GitHub Actions 自动运行。

## 计算内容

| 字段 | 含义 |
|---|---|
| `vix_csi1000` | 用**中证1000股指期权**（中金所 MO）近月、次月完整报价，按 Cboe VIX 方法计算的30天隐含波动率指数，代表中小盘成长股情绪 |
| `vix_csi300` | 同上，用**沪深300股指期权**（中金所 IO）计算，代表大盘蓝筹情绪 |
| `qvix_*` | 期权论坛发布的 QVIX 各版本收盘值（50ETF、300ETF、500ETF、创业板、科创板、沪深300指数、中证1000指数），用于核对 |

## 方法

单个到期月的方差：

$$\sigma^2=\frac{2}{T}\sum_i\frac{\Delta K_i}{K_i^2}e^{RT}Q(K_i)-\frac{1}{T}\left(\frac{F}{K_0}-1\right)^2$$

近月与次月方差按剩余时间线性插值到30天，再开方乘以100。细节见 `vix_calc.py` 注释。

- 近月剩余不足7天时换用下一个月（与原上交所 iVIX 一致）
- 期权价格用买卖中间价；收盘后买卖价缺失时用最新价
- 到期日按每月第三个星期五15:00计（遇节假日顺延的情况未处理，误差很小）
- 无风险利率固定取1.5%（对结果影响很小）

## 文件

- `data/a_share_vix.csv`：每日一行，累积时间序列
- `data/latest.json`：最近一次运行结果
- `data/qvix_history.csv`：QVIX 全部历史（每次运行覆盖更新）
- `data/chains/`：每天用于计算的原始期权报价，便于核查

## 数据来源

新浪财经期权行情接口、期权论坛（optbbs.com）。接口调用方式参考开源项目 [AKShare](https://github.com/akfamily/akshare)。数据仅供研究参考，不构成投资建议。
